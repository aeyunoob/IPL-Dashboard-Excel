
IPL Dashboard – Excel Data Analytics Project

Overview

This project is an interactive IPL (Indian Premier League) Dashboard built completely in Microsoft Excel. The dashboard provides insights into IPL matches, toss decisions, venue statistics, player performances, and title winners using data visualization techniques.

The goal of this project is to analyze IPL data and present it in a clean, interactive, and visually appealing format.


Features

1.Interactive Excel Dashboard

2.KPI cards for quick insights

3.Match analysis based on:

    •Batting first vs fielding first wins

    •Toss-based decisions

    •Top 10 venues

    •Man of the Match winners

    •IPL title winners


4.Slicers and filters for dynamic analysis

5.Charts and visualizations for better understanding

---

Dashboard Sections

1. Match Wins Analysis

Shows the comparison between teams winning while:

•Batting first

•Fielding first


2. Toss Decision Analysis

Analyzes how toss decisions affect match outcomes.

3. Top Venues

Displays the venues hosting the maximum IPL matches.

4. Man of the Match Analysis

Highlights players with the most Man of the Match awards.

5. IPL Winners List

Shows season-wise IPL champions.
